# Shared GitHub settings

Default files for all of spodg13's repositories.

- `ISSUE_TEMPLATE/enhancement.yml`: the **Enhancement idea** form. It appears under
  **Issues → New issue** in every repository that doesn't have its own issue forms, and
  labels new issues `enhancement`.
- `ISSUE_TEMPLATE/bug.yml`: the **Problem report** form, which labels new issues `bug`.

A repository with its own `.github/ISSUE_TEMPLATE` folder uses that instead.
